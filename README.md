# Procesos y Planificación de Procesos

Taller web explicativo para estudiantes que están empezando con Sistemas Operativos.

## Contenido

- Qué es un proceso
- PID, PCB y estados
- Procesos padre, hijo y huérfanos
- Planificación apropiativa y no apropiativa
- Métricas básicas
- FCFS
- SJF
- Planificación por prioridad
- Round Robin
- Colas multinivel
- Introducción a MLFQ
- Código básico en Java y Python usando un objeto `Proceso`
- Diagramas, ejercicios y repaso final

El sitio principal está en `index.html` y se publica automáticamente con GitHub Pages.


## Mejoras visuales de los diagramas

Los diagramas del taller usan librerías externas para hacer la explicación más visual e interactiva:

- **Mermaid** para construir diagramas y flujos.
- **Panzoom** para mover y ampliar los diagramas.
- **Tippy.js** para ayudas emergentes.
- **Lucide Icons** para los controles visuales.
- **AOS** para animaciones de entrada.
- **Highlight.js** para resaltar el código Java y Python.

Los diagramas incluyen controles para acercar, restablecer y abrir una vista ampliada.
